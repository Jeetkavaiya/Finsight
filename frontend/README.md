# FinSight — Frontend

React 18 + Vite frontend for the FinSight SEC filing intelligence tool.

## Setup

```env
# frontend/.env
VITE_API_URL=http://localhost:8000
```

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # production build
```

## Stack

- React 18, Vite
- react-markdown (cited answer rendering)
- Custom CSS — Space Grotesk, JetBrains Mono, Inter

Deployed on Vercel. See root [README](../README.md) for full documentation.
